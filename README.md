- ¿Qué diferencia notaste entre write() y append()?
 cuando abres con write se posiciona al principio al inicio del archivo. Cuando abres con append se posiciona al final. listo para agregar al final nuevos datos.

- ¿Qué ventaja tiene usar with open(...) frente a abrir y cerrar manualmente

 te garantizas que el archivo se cerrará de forma automatica en cuanto el bloque de código termine, incluso si ocurre un error inesperado dentro del bloque. en cambio con el open no pasaria lo mismo
