2. Consultas entre varias tablas
Responde lo siguiente en respuestas.md y realiza las consultas en consultas_sql.sql:


    • ¿Qué es un modelo de datos y para qué sirve en bases relacionales?
  
        Es como un plano para crear la base de datos. Determina cómo se estructuran, almacenan y relacionan los datos entre sí.

    • ¿Qué es una clave foránea y qué garantiza?

        Es una columna  en una tabla que actúa como un puntero hacia la clave primaria de otra tabla.Su función principal es mantener la Integridad Referencial. Esto significa que garantiza que las relaciones entre los datos siempre sean válidas y consistentes
